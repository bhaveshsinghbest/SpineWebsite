# Database

- `migrations/`: SQL migrations generated by Drizzle from `backend/src/models/schema.ts` (`npm run db:generate` in `backend/`). They are applied with `npm run db:migrate`. Never edit a migration that has already been applied; generate a new one.
- `seeds/`: the original website's content, copied unchanged from the Astro site (`content/*.ts`: company, services, sectors, industries, pillars, articles, redirects; `yaml/`: job openings and testimonials; `media/`: team photos). `npm run db:seed` loads it into PostgreSQL.
- `schema/`: the database structure for reference (`schema.md`).
- `scripts/`: `setup-database.ps1` / `.sql` (create the role and databases). Backups are made with `npm run db:backup` in `backend/` into `backups/` (not committed).
